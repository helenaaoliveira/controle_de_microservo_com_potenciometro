# Controle de Microservo com Potenciômetro

### Descrição da Atividade:

Nesta atividade, foi realizada a integração de um potenciômetro e um microservo com um Arduino, utilizando o Tinkercad. O potenciômetro funciona como dispositivo de entrada, enviando valores ao Arduino, que os interpreta e controla a posição do microservo de acordo com a rotação realizada. A prática demonstra a utilização de sensores e atuadores em projetos de IoT.
